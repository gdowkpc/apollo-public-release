# Apollo public releases

This is the official public binary-release repository for Apollo. It contains
only materials intentionally prepared for public distribution; Apollo source
development and private provenance remain separate.

Downloadable builds are published through the
[GitHub Releases](https://github.com/gdowkpc/apollo-public-release/releases)
page. Large release binaries are release assets, not files committed to this
repository.

## Platform families

### Android / CJ-1

Apollo for the Cignus / CJ-1 platform.

### Windows

Apollo passive receiver for supported Windows SDR/radio configurations.

### Raspberry Pi / Linux ARM64

Apollo passive receiver for supported Raspberry Pi/Linux configurations.

### Other platforms

Future supported Apollo release builds may be published in this repository.

## Release index

No Apollo binaries are currently authorized for public download.

Listed platform families do not imply that a public build is currently
available for each platform. See the [Releases](https://github.com/gdowkpc/apollo-public-release/releases)
page for available builds.

## Publication policy

Apollo binary and build assets are published here only after explicit
authorization for that specific publication. Development, early, RC, beta,
test, fixture, and qualification artifacts are not public release assets.

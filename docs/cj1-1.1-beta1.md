# Apollo CJ-1 1.1 Beta 1 installation

Use this optional beta on supported ARM64 CJ-1 hardware. Stable 1.0 / Build 116
remains available from the [download page](https://www.repeaterbooklive.com/apollo/downloads/).

1. Download [Apollo-CJ1-1.1-beta1-build117.apk](https://github.com/gdowkpc/apollo-public-release/releases/download/cj1-v1.1.0-beta1-build117/Apollo-CJ1-1.1-beta1-build117.apk).
2. Verify SHA-256 `ade7099d2e411eaff16fb08fb11638781c134e4b256af23031223752647c47eb`; size is 76,903,265 bytes.
   On Windows: `certutil -hashfile Apollo-CJ1-1.1-beta1-build117.apk SHA256`.
3. Open the downloaded APK on the CJ-1 and accept the Android update, or use
   an authorized ADB connection and `adb install -r Apollo-CJ1-1.1-beta1-build117.apk`.
   Preserve the existing app data. If installation fails, stop rather than
   uninstalling or clearing data.
4. Open **Apollo Listening**, select **Start**, and confirm receiver startup
   and changing scan frequencies. Existing users keep their node identity,
   credentials, settings and scan plan. No new sign-in is needed for this upgrade.

For first setup, follow the [CJ-1 owner guide](cj1.md#first-use).
Android shows `1.1.0-dev.1` / Build `117`. If Build 117 is already installed,
this is the same APK and reinstallation is unnecessary.

Read the [beta release notes](../release-notes/cj1-v1.1.0-beta1-build117.md)
for CTCSS improvements, test evidence and short-transmission/gap limitations.
Android normally prevents downgrading to Build 116. Do not uninstall to force
a downgrade, because that erases app state and node identity.

# Apollo CJ-1 1.1 Beta 2 installation

Use this optional beta on supported ARM64 CJ-1 hardware. Stable 1.0 / Build 116
remains available from the [download page](https://www.repeaterbooklive.com/apollo/downloads/).

1. Download `Apollo-CJ1-1.1-beta2-build118.apk` from this release.
2. Verify SHA-256 `dfe37d801f089795bef880646b971e78641e5783b422af330c0f95b5ec21c12e`.
   On Windows: `certutil -hashfile Apollo-CJ1-1.1-beta2-build118.apk SHA256`.
3. Open the downloaded APK on the CJ-1 and accept the Android update, or use
   an authorized ADB connection and `adb install -r Apollo-CJ1-1.1-beta2-build118.apk`.
   Preserve existing app data. If installation fails, stop rather than
   uninstalling or clearing data.
4. Open **Apollo Listening**, select **Start**, and confirm receiver startup
   and changing scan frequencies. Existing node identity, credentials, settings,
   and scan plan remain in place.

When Apollo is running with its existing node credential and network delivery
enabled, Beta 2 sends an authenticated status check-in at most every five
minutes. It does not delay scanning or evidence delivery.

Android shows `1.1.0-dev.2` / Build `118`. Read the [beta release notes](../release-notes/cj1-v1.1.0-beta2-build118.md) for the validation scope and CTCSS limitations.
